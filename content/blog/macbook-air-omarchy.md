2013 年，我还在读书，用学生优惠买了自己的第一台 Mac，一台 13 英寸 MacBook Air。我目前的个人主力是一台 MacBook Pro M1，所以这台 Air 大概有四年没怎么开过机，一直躺在抽屉里。卖也卖不了几个钱，扔掉又觉得可惜。

最近 DHH 做的 Omarchy 很火，我正好想找台机器试试，就把它翻了出来。折腾完以后，这台已经 13 岁的电脑不但重新成为了一台开发机，连今天的企业办公软件也基本跑通了。

## DHH 的大号 dotfiles

[Omarchy](https://github.com/omacom/omarchy) 官方把它称作 DHH 发布的一套“强调个人取向”的 Arch Linux 发行版。对我来说，它更像 DHH 的大号 dotfiles：从操作系统、桌面到日常应用，全都替你选好了。

这也是“omakase”的意思：不让用户从几十种终端、编辑器和窗口管理器里逐一选择，而是由作者直接端上一套组合。喜欢的人装完就能干活，不喜欢的人大概第一天就会想把它拆掉。

好在 DHH 的很多选择和我的习惯很接近。Neovim、fzf、ripgrep、zoxide、tmux 都是我平时会用的工具，Pi 和 Codex 也已经进入日常工作流。

## 安装比我想象中简单

这台机器的型号是 `MacBookAir6,2`，8GB 内存，128GB SSD。这套配置放到今天并不宽裕，不过跑终端、编辑器和浏览器还够用，也正适合拿来做不怕重装的 Linux 实验机。

安装过程没有太多故事。我下载 Omarchy ISO，用 balenaEtcher 写进 U 盘，开机时按住 `Option`，然后选择 `EFI Boot`。进入安装器以后清空整块 SSD，安装系统并启用磁盘加密。

网上不少 Mac 安装 Linux 的文章会提到关闭 Secure Boot 或 SIP。我的这台是 2013 年的 Intel Mac，没有 T2 芯片，实际什么安全设置都没改，只需按住 `Option` 选择 U 盘。较新的 Intel Mac 应以官方的 [Mac 支持说明](https://github.com/omacom/omarchy/blob/quattro/manual/44-mac-support.md)为准。

第一次启动后，屏幕、键盘、触控板和 Wi-Fi 都能正常使用，没有卡在基础硬件兼容上。

## 最陌生的是 Hyprland

Omarchy 里面最让我觉得新鲜的并不是那些开发工具，而是 [Hyprland](https://hypr.land/)。我以前没有认真用过平铺式窗口管理器，习惯了在 macOS 上拖动和堆叠窗口，刚开始确实会下意识地找标题栏。

适应以后，它的思路倒很直接：窗口自动占据合适的位置，用快捷键切换焦点和 workspace，很少需要拿鼠标整理桌面。写代码、看文档、开终端这类工作天然适合平铺布局。MacBook 的 Command、Option 和 PC 键盘的 Super、Alt 不完全对应，肌肉记忆还要重新训练。

现在我反而开始考虑在主力 Mac 上也装一个类似的平铺窗口管理工具。以前觉得这类软件只是 Linux 用户的特殊爱好，用过以后才发现，它确实提供了另一种组织桌面的方式。

## 从开发机到工作机

如果只是装 Neovim、Git、容器和 coding agent，Linux 能做开发早就不是什么新闻。真正值得验证的是，这台 13 年前的机器能不能跑通今天的企业办公软件。

中文输入和本机代理很快就能配好，微信有官方 Linux 客户端。企业微信麻烦一点，我借助社区提供的 Wine 环境运行官网的 Windows 客户端。公司的深信服 aTrust VPN 也可以启动；只提供 Ubuntu 安装包的云桌面客户端，则被我放进一个 Ubuntu 容器里，通过宿主机的 VPN 路由连接。

这些当然不是全部开箱即用。企业微信出现过奇怪的透明边框，aTrust 遇到过新旧 OpenSSL 库冲突，云桌面也曾在启动后直接消失。它们最后分别靠窗口规则、一个只对 aTrust 生效的小兼容库和 Ubuntu 容器解决。

这些排查大多由 Codex 通过 SSH 完成。它读日志、检查进程、修改脚本，我负责登录、扫码和判断结果是否真的可用。以前遇到这种小众兼容问题，我大概搜索半天就放弃了；现在可以让 coding agent 持续追到一个能解释、能回滚的方案。

但 Codex 也无法抹平所有兼容问题。目前云桌面里的 Win 键和 Alt+Tab 仍然不能正常工作，开始菜单和切换窗口要靠鼠标。几种按键映射方案反而让我一度无法退出云桌面，最后只好全部撤回。能用和好用之间，还是有一点距离。

## Linux 已经非常可用，Omarchy 对我仍是玩具

用 Linux 工作，对我并不是一件新鲜事。读书和工作期间，我都曾长期使用 Ubuntu 作为主力系统。今天的 Linux 桌面已经比当年完整得多：日常通信和办公软件基本有办法解决；随着 Steam 和 Proton 的持续投入，很多原本只能在 Windows 上玩的游戏也能在 Linux 上运行。过去的问题往往是某个软件根本不能用，现在更多只是存在一点兼容细节。

不过 Omarchy 对我来说仍然更像一个玩具。它很漂亮，也很有趣，Hyprland 和 DHH 那套高度个人化的选择值得体验，但我暂时不会把一套基于 Arch、持续滚动更新的系统放到最重要的工作电脑上。这台旧 MacBook Air 正适合它：系统折腾坏了可以重装，遇到问题也可以慢慢研究。

如果现在要买一台新的 Linux 笔记本，我甚至会认真考虑 XPS 13 加 Ubuntu。作为长期使用的工作和生活系统，Ubuntu LTS 的发行节奏更稳，文档和硬件适配更成熟，遇到问题也更容易找到经验。国内软件尤其如此：不少厂商即使提供 Linux 版本，首先支持的通常也是 Ubuntu 和 `.deb` 包，而不是 Arch。

Omarchy 没有改变我对主力系统的选择，但它让这台在抽屉里躺了四年的 MacBook Air 重新有了用途。更重要的是，它再次确认了一件事：Linux 桌面早已不只是玩具，只是 Omarchy 对我而言仍是。
